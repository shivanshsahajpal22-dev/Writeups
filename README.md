A growing collection of **CTF write-ups, technical guides, and command references** — covering everything from full challenge walkthroughs to the small, useful things I pick up along the way. | Area | Description |

---

## 🧠 Philosophy

Write-ups here follow a simple structure per challenge:

1. **Challenge summary** — category, difficulty, and what's given
2. **Recon / enumeration** — what was found and how
3. **Exploitation path** — the reasoning that led to the flag, not just the final payload
4. **Lessons learned** — what this challenge taught, so it's useful beyond just that one CTF

Most other content in here is just kept close to how I actually reference it day to day — practical over polished.
